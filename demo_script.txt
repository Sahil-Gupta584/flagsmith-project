Hey wassup team, let me strat the demo with a question, how can a startup team manage there flags?

1. thourgh dashboard
2. using cli
3. using mcp 

but the problem is all of them requires authentication even just to read the flags.

i mean, flag configurations are trapped outside the codebase, and there is no declarative way to manage flags.

If a new developer joins the team, he can't even see what flags exist or what 
their defaults are without asking an admin for dashboard invites or API keys!

thats why i built an integration so that a team can manage there flags through a single yaml file.

now if a memeber in team is want to work on flags he dont need to ask his admin to give me access to dahabord or list of flags.

he can just make a yaml file and use his own flagsmith account for developement and testing.

I wanted to give Flagsmith the declarative GitOps workflow that Prisma and 
Drizzle brought for databases.
